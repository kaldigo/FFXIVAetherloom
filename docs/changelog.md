Folder right-click menus open directly on their actions. The design title now includes a per-design ownership bypass for Apply to character. With bypass off, unavailable gear and its dyes are skipped.

Job and zone assignments now apply the assigned design using the same ownership bypass as manual application. A zone assignment takes priority and leaving it restores the current job assignment.

The Details tab edits the design’s intended audience and its Classification, Style, Theme, Color, and freeform tags. The wardrobe sidebar combines text search with filters for these fields and configured weapon jobs. Existing tags remain searchable.
